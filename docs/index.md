# RBFLAB

RBFLAB provides radial basis function interpolation and point-cloud discretizations for linear PDEs. Its public Python API includes global collocation, local Hermite interpolation (LHI), RBF-FD, symbolic equations, and divergence-free spaces.

Start with [a symbolic Poisson problem](getting-started.md), then use the [API reference](api/discretizations.md) for constructor parameters and numerical conventions. The [capability table](CAPABILITIES.md) records which methods, dimensions, and backends are supported.

The default installation is Python-only. Optional C++, PyTorch, Gmsh, and extended-precision workflows are described in the [installation guide](INSTALL.md).
